# Практична робота №2
## Списки

Зверстати текст про цілі комерційних Web-сторінок і принципи їх побудови за допомогою
маркованих та нумерованих списків, включно з вкладеними.

## Що використано

- `<ul>` — маркований список цілей компаній;
- `<ol type="I">` — нумерація римськими цифрами для трьох груп принципів;
- `<ol type="1">` — вкладені нумеровані списки всередині кожної групи;
- третій рівень вкладеності — «Пошук інформації» та «Аналіз інформації».

Вкладений список ставиться **всередину** `<li>` батьківського пункту, а не поруч із ним, —
інакше він не прив'язується до пункту і зсуває нумерацію.

## Запуск

Відкрити [`index.html`](index.html) у браузері.
