# Практична робота №1
## Таблиці

Побудувати таблицю з об'єднаними комірками за заданою схемою (таблиця №4).

## Що використано

- `<table>`, `<tr>`, `<td>` — базова структура таблиці;
- `colspan` — об'єднання комірок по горизонталі;
- `rowspan` — об'єднання комірок по вертикалі;
- `<caption align="bottom">` — підпис під таблицею.

Найскладніше місце — «Комірка 9»: вона займає дві колонки і два рядки одночасно
(`colspan="2" rowspan="2"`), тому в наступному рядку треба пропустити дві позиції.

## Запуск

Відкрити [`index.html`](index.html) у браузері.
