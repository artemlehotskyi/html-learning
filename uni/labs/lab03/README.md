# Практична робота №3
## Форми

Створити форму реєстрації на студентський IT-хакатон 2026 з валідацією засобами HTML,
без JavaScript.

## Що використано

**Структура:** `<form>`, `<fieldset>` + `<legend>` — п'ять логічних блоків: особисті дані,
навчання, участь у хакатоні, акаунт, згоди.

**Типи полів:**

| Тип | Де |
|---|---|
| `text`, `email`, `tel`, `url`, `password` | контакти, логін, GitHub |
| `date`, `time`, `color` | дата народження, час старту, колір команди |
| `radio`, `checkbox` | стать, напрям, технології, харчування, згоди |
| `<select>`, `<datalist>`, `<textarea>` | розмір футболки, університет, мотивація |

**Валідація без JS:**

- `required` — обов'язкові поля (позначені `*` з підказкою через `<abbr>`);
- `pattern` — телефон `+380XXXXXXXXX`, логін лише з латиниці, цифр і `_`;
- `minlength` / `maxlength` — довжина логіна, пароля, мотивації;
- `min` / `max` — діапазон дати народження і часу старту.

## Запуск

Відкрити [`index.html`](index.html) у браузері.
