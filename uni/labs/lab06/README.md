# Практична робота №6
## Способи підключення CSS

Оформити один і той самий текст трьома способами підключення стилів. Результат
на всіх трьох сторінках однаковий: `<p>` червоні, `<div>` зелені. Різниця лише в тому,
**де** лежать правила.

## Три способи

| Сторінка | Спосіб | Де правило |
|---|---|---|
| [`index1.html`](index1.html) | зовнішній | окремий файл [`css/style.css`](css/style.css), `<link rel="stylesheet">` |
| [`index2.html`](index2.html) | внутрішній | тег `<style>` усередині `<head>` |
| [`index3.html`](index3.html) | вбудований | атрибут `style="…"` на кожному тезі |

Зовнішній файл — основний варіант: одне правило діє на всі сторінки, які його
підключають. Вбудований стиль доводиться повторювати на кожному елементі, тому в
`index3.html` `color: red` написано чотири рази.

## Цікаве місце

`<p>` усередині зеленого `<div>` все одно червоний. Колір успадковується від батька
лише тоді, коли в самого елемента немає свого правила. А для `<p>` таке правило є,
тому успадкування не спрацьовує.

## Запуск

Відкрити будь-яку з трьох сторінок у браузері.
