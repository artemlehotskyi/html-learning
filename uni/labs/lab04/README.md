# Практична робота №4
## Мультимедіа

Вбудувати на сторінку чотири види медіа: власне відео, аудіо, ролик з YouTube і з Vimeo.

## Що використано

| Що | Як |
|---|---|
| Відео | `<video controls>` + `<source type="video/mp4">` |
| Аудіо | `<audio controls>` + `<source type="audio/mpeg">` |
| YouTube | `<iframe>` з `youtube.com/embed/…` |
| Vimeo | `<iframe>` у контейнері з `padding: 56.25%` |

Текст усередині `<video>` / `<audio>` — запасний варіант: його видно лише тоді, коли
браузер не вміє відтворити медіа.

`56.25%` — це 9 / 16: відступ у відсотках рахується від **ширини** батька, тому контейнер
завжди тримає пропорцію 16:9, а `iframe` з `position: absolute` просто заповнює його.

## Запуск

Відкрити [`index.html`](index.html) у браузері. Відео й аудіо лежать у [`media/`](media).
