# Практична робота №9
## Flexbox

Десять вправ на flex-контейнер: однакові квадрати 60×60, а різниця лише в правилах
`.taskN`. Перші п'ять — базові, наступні п'ять — складніші.

## Вправи

| № | Задача | Ключові властивості |
|---|---|---|
| 1 | Центрування | `justify-content: center` + `align-items: center` |
| 2 | Рівномірний розподіл | `justify-content: space-evenly` |
| 3 | Колонка | `flex-direction: column` |
| 4 | Перенос рядків | `flex-wrap: wrap`, `width: 204px`, `align-content` |
| 5 | Розподіл з проміжками | `justify-content: space-between` |
| 6 | Вирівнювання по краях | `justify-content: space-between` |
| 7 | Центрування з обмеженням | `align-items: flex-start` + `padding-top` |
| 8 | Різні розміри | `:nth-child(n)` задає кожному квадрату свій розмір |
| 9 | Двоколонкова сітка | `flex-wrap: wrap`, `width: 204px` |
| 10 | Адаптивна обгортка | `flex-wrap`, `space-evenly`, `max-width: 100%` |

## Цікаве місце

Чому саме `204px` у вправах 4 і 9: 3 квадрати × 60px + 2 проміжки × 12px (`gap`) = 204px.
Контейнер рівно такої ширини вміщує три квадрати в рядку, тож четвертий переноситься.
Так з шести квадратів виходять два рядки по три без жодної сітки.

`justify-content` вирівнює вздовж головної осі, `align-items` — поперек неї. У вправі 3
`flex-direction: column` повертає головну вісь вертикально, тому центрування по
горизонталі там робить уже `align-items`.
