# Практична робота №5
## Семантична розмітка

Зверстати сторінку блогу лише семантичними тегами, без `<div>`: шапка з навігацією,
стаття з коментарями, бічна панель і футер.

## Каркас сторінки

```
<header>   — назва блогу + <nav> з меню
<main>
  <article>    — пост
    <section>  — блок коментарів
      <article> × 3 — кожен коментар
<aside>    — інші статті, категорії
<footer>   — копірайт + <address>
```

## Що використано

| Тег | Навіщо |
|---|---|
| `<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>` | великі зони сторінки |
| `<article>` | самодостатній контент: пост і кожен коментар |
| `<section>` | тематична група всередині поста |
| `<time datetime="…">` | дата, яку розуміє машина |
| `<address>` | контакти автора |
| `<strong>` / `<b>`, `<em>` / `<i>` | логічне і фізичне виділення |
| `<mark>`, `<code>` | підсвітка і фрагмент коду |

Коментар — теж `<article>`, бо має сенс окремо від сторінки: його можна винести,
процитувати чи показати в стрічці, і він залишиться зрозумілим.

`<strong>` і `<b>` виглядають однаково, але `<strong>` означає «це важливо», а `<b>` —
лише жирний шрифт. Так само `<em>` (наголос) і `<i>` (курсив).
